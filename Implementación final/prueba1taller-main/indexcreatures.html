machine learning: Creatures

Usa una imitación de neuronas reales

El modelo de Creator Labs registra
necesidades de territorio,
cosas ficticias como el "hambre",
y estímulos desde el jugador

El cerebro artificial
analiza en tiempo real cada estímulo
(como una palabra nueva) y aprende.

A partir de este análisis y circunstancias,
el NPC puede adaptar sus movimientos
y lenguaje para asegurar su supervivencia.
¡Como un animal real!

Cada movimiento se genera
entonces de forma dinámica
y natural, sin depender únicamente
de reacciones preprogramadas.
